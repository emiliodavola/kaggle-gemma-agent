INVENTORY ONLY. No ranking, no scoring, no winners, no stack selection. A later stage evaluates and builds `skill-stack/`.

Methods: every SKILL.md below was read in full (frontmatter + body); repo dates from `git log -1`; licenses from LICENSE files/readmes. Web search backends were unavailable, so evidence came from `raw.githubusercontent.com`, shallow sparse clones, and GitHub tree pages. No Grokpedia. No invented URLs. Similar duplicates kept with differences noted.

## A. Competition — skill-relevant constraints

- **Deliverable:** `submission.zip` = `agent.yaml` (root config, declarative ONLY — no `agent.py`, no `importlib`, closed registries) + optional `eval_config.yaml`, `configs/`, `prompts/*.md`, `sub_agents/*.yaml`, `adapters/<name>/` (PEFT LoRA: `adapter_config.json` + `adapter_model.safetensors`), `skills/<dir>/SKILL.md`.
- **Model:** single base model `gemma-4-31b-it-qat-w4a16-ct` (INT4 QAT, ~16–18 GB across 4 GPUs). All agents share it; different agents may each mount a different LoRA (`max_loras=8`, `max_lora_rank=128`). Total unpacked submission `< 3 GiB`.
- **Serving:** vLLM, `tensor_parallel_size=4`, `max_model_len=32768`, OpenAI-compatible `/v1`, `tool_call_parser=gemma4`.
- **Agent tools (9, sandbox-bound):** `run_command` (bash, 300 s timeout, 5000-char output cap), `submit_patch` (free, ends loop), `get_status` (free), `read_file` (150 lines / 10000 chars cap), `edit_file` (3-tier resilient match), `write_file`, `get_code_neighbors`, `search_similar_code` (offline embedding lookup — pass SYMBOLS, not prose), `get_code_subgraph`.
- **Budgets per task:** 60 min wall-clock, 100 tool calls, 500 turns, 3 continuation nudges. `submit_patch`/status calls are free.
- **Sandboxes:** two air-gapped Docker containers per task (A: agent works in `/workspace`; B: fresh snapshot + agent patch + hidden `test_patch` + hermetic pytest). No internet, no pip. Test files and runner configs touched by the patch are RESET before scoring — the agent must fix library code only.
- **Metric:** Resolution Rate = resolved/total (pytest exit 0 + valid JUnit XML, FAIL_TO_PASS + PASS_TO_PASS).
- **Skills in competition:** `skills/` dirs load as read-only context (SKILL.md + small refs). They cost context on every turn: keep them short, procedural, tool-mapped. No network, no MCP, no background processes from a skill.
- **Training happens OFF-Kaggle** (own hardware/cloud): SFT over successful harness trajectories → preference pairs (resolved vs failed) → RLVR with verifiable reward (patch passes tests). Adapters target bf16 weights, served over the QAT quant. Our reference box: RTX 3090 24 GB (QLoRA rank 8–16 realistic).
